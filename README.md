# First-Person Shooter

A lightweight browser-based 3D FPS prototype built with HTML, CSS, JavaScript, and Three.js. It includes a large arena, mouse-look controls, WASD movement, and a toggleable first-person/third-person camera.

## Features

- First-person and third-person camera modes
- Mouse-look with pointer lock
- WASD movement with camera-relative direction
- Smooth pacing and frame-rate independent motion
- Arena environment with lighting, fog, and grid floor
- Scroll wheel zoom control in third-person view

## Getting started

### Prerequisites

- Node.js 20.19+ or 22.12+
- A modern web browser

### Install and run

1. Open the project folder in VS Code.
2. In the terminal, run:

   ```bash
   npm install
   ```

3. Start the dev server:

   ```bash
   npm run dev
   ```

4. Open the local URL shown in the terminal, usually something like:

   ```text
   http://localhost:5173
   ```

### Build for production

```bash
npm run build
```

## Controls

- Move: `W`, `A`, `S`, `D`
- Look around: mouse movement
- Lock pointer / focus game: click inside the canvas
- Release pointer: `Esc`
- Switch camera view: `V`
- Zoom in third-person mode: mouse wheel

## Gameplay notes

- Click the game area to capture the mouse and look around.
- Press `Esc` to release the pointer when you want to stop aiming.
- Toggle between first-person and third-person view using `V`.
- In third-person mode, the player character remains visible and can be zoomed in/out with the mouse wheel.
